# Agent Coding × pen.dev UI 设计学习 GitBook

这是一个面向“主要依赖 Agent 开发前端、但缺少传统前端与 UI 设计基础”的中文学习项目。

- GitBook 内容根目录：`book/`
- 交互式 HTML 实验：`labs/`
- GitBook 配置：`.gitbook.yaml`
- GitBook Git Sync 分支：`main`

内容包括前端设计基础、Anthropic `frontend-design` Skill 解读、pen.dev 工作流、8 周训练计划、168+ 术语、设计验收工具，以及 7 个主题、8 个 HTML 入口的无依赖交互实验。

## 阅读内容

从 [`book/README.md`](book/README.md) 开始，完整目录见 [`book/SUMMARY.md`](book/SUMMARY.md)。

## 运行交互实验

打开 [`labs/index.html`](labs/index.html)，或使用公开静态预览：

- https://raw.githack.com/Cafeynman/agent-ui-design-gitbook/main/labs/index.html

每个实验均为单文件 HTML/CSS/JavaScript，可直接下载后在浏览器中运行。

## 导入 GitBook

1. 在 GitBook 新建 Space 或 Docs Site；
2. 启用 GitHub Sync；
3. 选择仓库 `Cafeynman/agent-ui-design-gitbook`；
4. 选择分支 `main`；
5. 首次同步方向选择 `GitHub → GitBook`；
6. GitBook 会读取根目录 `.gitbook.yaml`，并将 `book/` 作为内容根目录；
7. 将 Docs Site 发布为 Public。
