# 视觉层级

![视觉层级对比](../.gitbook/assets/visual-hierarchy.svg)

视觉层级回答：

> 第一眼、第二眼、第三眼，用户分别看见什么？

## 五个主要手段

1. **尺寸**：更大的元素通常更先被看见；
2. **对比**：亮暗、颜色、字重和形状差异；
3. **位置**：首屏、左上、中心等位置天然更突出；
4. **分组**：邻近、共同区域和对齐表达关系；
5. **留白**：通过空间隔离重点、形成节奏。

## Squint Test

把页面缩小，或轻微眯眼观察：

- 是否仍能看见主标题？
- 主 CTA 是否突出？
- 页面是否分成清楚的组？
- 有没有两个以上元素争夺最高权重？

## Agent Review 指令

```text
对当前选中的 Frame 做视觉层级审计。

请判断：
1. 第一眼看到什么；
2. 第二眼看到什么；
3. 主 CTA 是否明确；
4. 是否有多个元素争夺最高权重；
5. 哪些文字层级过近；
6. 哪些内容缺少分组；
7. 哪些边框或容器可以删除。

先创建 Annotated Review Frame，不直接修改原稿。
```
