# 页面类型、区域与营销结构


| 优先级 | 英文术语 | 常见中文 | 一句话理解 | Agent 验收问题 |
| --- | --- | --- | --- | --- |
| P0 | Homepage | 首页 | 网站总入口，通常同时服务多个受众和任务。 | 不要把首页强行做成只有一个转化目标的广告页。 |
| P0 | Landing page | 落地页 | 来自广告、邮件或分享链接的独立页面，通常聚焦一个短期目标。 | 是否只有一个清晰的主要行动？ |
| P0 | Hero section | 首屏核心区 | 页面顶部最吸引注意力的区域；不是一种 Page。 | 五秒内能否说明是什么、给谁、价值和下一步？ |
| P0 | Above the fold | 首屏可见范围 | 用户尚未滚动时看到的内容；会随设备变化。 | 小屏首屏是否仍看到核心价值和主要行动？ |
| P0 | Header | 页头 | 页面顶部容器，可含品牌、导航、搜索、账户和行动。 | 是否承担了过多功能？ |
| P0 | Navbar | 导航栏 | 帮助用户在主要区域间移动的导航组件。 | 命名是否使用用户熟悉的词？ |
| P0 | Sidebar | 侧边栏 | 位于侧面的导航、筛选或工具区，常见于后台应用。 | 窄屏时如何折叠、抽屉化或重排？ |
| P0 | Main content | 主内容区 | 当前页面真正完成任务的核心区域。 | 是否明显区别于辅助导航和次要信息？ |
| P0 | Section | 页面区块 | 围绕一个主题或任务组织的一组相关内容。 | 每个区块是否只有一个明确作用？ |
| P0 | CTA | 行动号召 | 引导下一步的按钮或链接，如“开始试用”。 | 文案是否直接说明点击后的结果？ |
| P0 | Primary / Secondary CTA | 主次行动 | 主行动是最希望发生的行为；次行动提供替代路径。 | 主行动是否明显，而不是两个按钮同样抢眼？ |
| P0 | Value proposition | 价值主张 | 解释产品为谁解决什么问题，以及为何值得选择。 | 是否写用户结果，而不只是功能清单？ |
| P0 | Feature section | 功能区 | 介绍产品能力的区块。 | 每项功能是否关联具体收益或场景？ |
| P0 | Benefit | 用户收益 | 用户因功能而获得的结果，如节省时间、降低风险。 | 有没有把“我们有什么”改成“用户得到什么”？ |
| P1 | Social proof | 社会证明 | 用真实客户、评价、案例、使用量或认证降低不确定性。 | 证据是否真实、具体，并靠近相应主张？ |
| P1 | Testimonial | 用户证言 | 客户对产品体验或结果的评价。 | 是否有可核验身份、场景和结果？ |
| P1 | Logo wall | 客户 Logo 墙 | 展示客户或合作方标识的信任区块。 | 是否有授权且确实相关？不要虚构。 |
| P1 | Case study | 案例研究 | 用问题、过程和结果说明产品如何产生价值。 | 是否包含可理解的前后变化？ |
| P1 | Pricing section | 定价区 | 比较方案、价格、限制和推荐选择。 | 差异是否易扫读，推荐是否有依据？ |
| P1 | FAQ | 常见问题 | 处理用户决策前的疑虑。 | 问题是否来自真实阻碍，而非重复营销？ |
| P1 | Final CTA | 页尾行动区 | 看完主要论证后再次给出下一步。 | 是否与首屏主行动保持同一名称和承诺？ |
| P0 | Footer | 页脚 | 底部辅助导航、法律信息、联系方式和次要入口。 | 是否把关键任务错误地藏在页脚？ |
| P0 | Dashboard | 仪表盘 | 汇总状态、指标和待办的应用页面。 | 指标是否支持决策，而不是为了有数据而堆数字？ |
| P0 | Onboarding | 新手引导 | 帮助新用户完成首次理解、配置或成功任务。 | 是否尽快让用户完成一个有价值的动作？ |
| P1 | Settings | 设置页 | 管理偏好、账户、权限、集成或系统行为。 | 分组是否符合心智模型，危险操作是否隔离？ |
| P1 | Checkout | 结算流程 | 从确认方案到支付完成的多步骤任务。 | 是否减少无关信息并明确费用、进度和错误恢复？ |
| P0 | List page | 列表页 | 浏览、搜索、筛选和批量处理多个对象。 | 密度、排序、筛选和空状态是否支持任务？ |
| P0 | Detail page | 详情页 | 查看和操作单个对象的完整信息。 | 主要状态和关键行动是否在明显位置？ |
| P1 | Search results | 搜索结果页 | 展示查询结果、筛选、排序和无结果反馈。 | 无结果时是否解释原因并提供下一步？ |
