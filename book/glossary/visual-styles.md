# 视觉设计与风格术语


| 优先级 | 英文术语 | 常见中文 | 一句话理解 | Agent 验收问题 |
| --- | --- | --- | --- | --- |
| P0 | Visual hierarchy | 视觉层级 | 用大小、位置、对比和分组安排阅读顺序。 | 快速扫视时，核心标题和行动是否最明显？ |
| P0 | Contrast | 对比 | 通过大小、颜色、字重、形状等制造差异。 | 不同层级是否真有差异，而非都在抢眼？ |
| P0 | Scale | 尺度 | 利用尺寸表达重要性和层级。 | 大元素是否真重要，还是只为视觉冲击？ |
| P0 | Proximity | 亲密性 / 邻近 | 相近的元素会被理解为一组。 | 相关内容是否靠近，不相关内容是否分开？ |
| P0 | Alignment | 对齐 | 用共同边线建立秩序和关系。 | 是否存在无理由偏移或过多竞争对齐线？ |
| P0 | Repetition | 重复 | 重复字体、间距、形状和模式以建立一致性。 | 同类对象是否长得和表现得一致？ |
| P0 | Consistency | 一致性 | 相同概念使用相同名称、外观和行为。 | 同一动作在按钮、提示和结果中是否同名？ |
| P0 | Whitespace | 留白 | 元素之间有意义的空白，用于分组和强调。 | 空白是否表达关系，而不是随机大间距？ |
| P1 | Density | 信息密度 | 单位空间内的信息和控件数量。 | 是否与任务匹配：营销页可疏，数据工具可更密？ |
| P0 | Grid | 网格 | 用于组织列、行和对齐的隐形结构。 | 页面是否有稳定的对齐和节奏？ |
| P0 | Container | 内容容器 | 限制并居中内容宽度的区域。 | 宽屏正文是否过长，小屏是否有合理边距？ |
| P1 | Gutter | 列间距 | 网格列之间或页面边缘的间隔。 | 不同区块的列间距是否一致？ |
| P0 | Spacing scale | 间距尺度 | 使用少量规则化间距，而不是每处随意决定。 | 相同关系是否使用相同间距？ |
| P0 | Typography | 字体排版 | 字体选择及字号、字重、行距、字距、行宽的整体系统。 | 层级、可读性和品牌气质是否同时成立？ |
| P1 | Display / Body / Utility type | 展示字 / 正文字 / 功能字 | 分别用于品牌标题、长文阅读和标签数据。 | 角色是否清楚，还是每处都换字体？ |
| P0 | Type scale | 字号层级 | 一组有规律的标题、正文和辅助字号。 | 层级数量是否适中，标题能否区分？ |
| P0 | Font weight | 字重 | 字体笔画粗细。 | 是否过度依赖粗体，导致没有重点？ |
| P0 | Line height | 行高 | 相邻文字基线的垂直距离。 | 长文本是否舒适，标题是否不过于松散？ |
| P1 | Letter spacing | 字距 | 字符之间的距离。 | 是否只在必要场景微调，避免中文过度拉开？ |
| P0 | Measure / Line length | 行宽 / 每行长度 | 一行正文的可读长度。 | 宽屏正文是否像一条超长横线？ |
| P0 | Color palette | 色板 | 项目中经过约束的一组颜色。 | 是否有主色、中性色和语义色？ |
| P0 | Neutral colors | 中性色 | 用于背景、文字、边框等结构的灰阶或低彩度色。 | 层级是否主要靠结构和中性色建立？ |
| P1 | Accent color | 强调色 | 用于吸引注意或表达品牌的少量高辨识颜色。 | 是否只用于真正重要位置？ |
| P0 | Semantic colors | 语义色 | 表示成功、警告、错误、信息等含义的颜色。 | 同一语义是否一致，且不只靠颜色？ |
| P1 | Border radius | 圆角 | 容器或控件角部的圆润程度。 | 是否有统一逻辑，避免所有东西都胶囊化？ |
| P1 | Shadow / Elevation | 阴影 / 层级高度 | 表达悬浮、覆盖或层次关系。 | 阴影是否表达层级，而非每张卡都装饰？ |
| P1 | Iconography | 图标体系 | 图标的风格、含义和使用规则。 | 陌生图标是否配文字？ |
| P1 | Imagery | 图像风格 | 照片、插画、截图或三维图的整体选择。 | 是否展示真实产品或主题，而非通用库存图？ |
| P1 | Art direction | 视觉指导 | 决定图像、构图、字体、颜色和氛围如何表达主题。 | 选择是否源自产品世界，而非流行模板？ |
| P0 | Visual identity | 视觉身份 | 让用户识别品牌的一致视觉语言。 | 遮住 Logo 后是否仍有自身特征？ |
| P0 | Signature element | 标志性元素 / 记忆点 | 最能体现主题的一处独特设计。 | 是否只在一处大胆，其余保持克制？ |
| P1 | Minimalism | 极简主义 | 减少元素，以空间、排版和精确细节取胜。 | 是不是信息缺失，而非真正简洁？ |
| P1 | Maximalism | 繁复主义 | 用丰富图形、层次和强表达营造高密度体验。 | 复杂度是否服务主题，执行是否足够精细？ |
| P2 | Editorial / Broadsheet | 编辑式 / 报刊式 | 借鉴杂志报纸的网格、标题、细线和栏目。 | 内容是否真适合阅读型结构？ |
| P2 | Bento grid | 便当盒网格 | 用大小不一的矩形模块组织内容。 | 模块大小是否表达优先级，还是无意义拼图？ |
| P2 | Glassmorphism | 玻璃拟态 | 半透明、模糊背景和高光营造玻璃感。 | 对比度和可读性是否受损？ |
| P2 | Neumorphism | 新拟态 | 用柔和内外阴影模拟凸起或凹陷。 | 控件边界与状态是否可辨认？ |
| P2 | Brutalism | 粗野主义 | 刻意直接、强对比、反精致的视觉风格。 | 是否符合品牌受众，而非为了另类？ |
| P2 | Skeuomorphism | 拟物化 | 让数字界面模拟现实材质或物件。 | 现实隐喻是否帮助理解？ |
| P1 | Dark mode | 深色模式 | 以深背景为主的模式，不等于简单反转颜色。 | 对比、图片、阴影和语义色是否重校准？ |

NN/g 将视觉层级概括为通过颜色与对比、尺度和分组等手段，引导用户按照设计者意图的重要性浏览内容。[^N5]
