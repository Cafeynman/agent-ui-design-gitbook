# 8 周学习计划

![8 周路线图](../.gitbook/assets/eight-week-roadmap.svg)

{% hint style="info" %}
默认每周 5 天、每天 45–60 分钟。时间不足时，优先保留“真实案例拆解、三个方向比较、截图 Review”三个动作。
{% endhint %}

## 最终能力

- 能看懂常见 UI/UX 术语；
- 能写设计 Brief；
- 能在 pen.dev 中比较方向；
- 能建立最小组件与变量系统；
- 能检查状态、响应式和无障碍；
- 能对设计与代码进行差异审计。

从左侧依次进入第 1–8 周。
