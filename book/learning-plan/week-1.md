# 第 1 周：认识 pen.dev，不追求漂亮

## 本周目标

- 建立 `.pen` 文件与保存习惯；
- 理解 Frame、Layer、Properties、Component；
- 学会选中元素后让 Agent 局部修改；
- 生成后必须 Review。

## Day 1：安装与连接

创建 1440×900 Frame，让 Agent 生成最简单登录页并截图。

## Day 2：画布结构

要求 Agent 解释 Frame、Layer、可组件化元素和无意义嵌套。

## Day 3：局部修改

依次修改尺寸、文案、间距、颜色；练习撤销和重新应用。

## Day 4：三个版本

同一登录页分别生成：极简、品牌感、企业可信三种方向。

## Day 5：第一份 Review

记录目标、用户、做得好的地方、最影响使用的三个问题，以及下一轮只修改什么。

## 通过标准

能解释 Frame、Component、Instance 的区别，并理解为什么先比较方向再精修。
