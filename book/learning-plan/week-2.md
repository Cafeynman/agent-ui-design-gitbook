# 第 2 周：页面结构与信息架构

## 核心概念

Homepage、Landing Page、Dashboard、Hero、Navbar、CTA、Section、Card、Grid、Social Proof、FAQ、Page’s Single Job。

## 练习

1. 从 Landbook 拆解三个页面；
2. 为 AI 论文工具做纯灰度 Landing Page；
3. 比较“产品 Demo 优先、价值证据优先、问题叙事优先”；
4. 做 Headline-led、Demo-led、Evidence-led 三种 Hero；
5. 删除重复和无助于转化的 Section。

## 产出

- 三种灰度结构；
- 三种 Hero；
- 一份区块取舍说明。
