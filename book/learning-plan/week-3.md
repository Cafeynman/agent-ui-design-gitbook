# 第 3 周：视觉层级、布局与间距

## 核心概念

Contrast、Scale、Proximity、Alignment、Whitespace、Grid、Density、Grouping、Scanability、Squint Test。

## 练习

1. 对现有 Wireframe 做 Squint Test；
2. 内容不变，只通过字号、字重、间距、对齐创建三种层级；
3. 制作“过密、合理、过散”间距对照板；
4. 创建 Annotated Review Frame 标出共同对齐线与不一致宽度；
5. 删除多余 Card、边框、背景色和装饰。

## 通过标准

能用具体语言描述层级、对齐、分组和视觉噪音，而不是只说“不够高级”。
