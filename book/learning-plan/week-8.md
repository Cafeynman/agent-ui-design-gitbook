# 第 8 周：Design ↔ Code 综合项目

## 选一个小而完整的产品

- AI 论文阅读工作台；
- 小团队任务管理器；
- 个人财务分类工具。

## 八个阶段

1. 一页 Design Brief；
2. 三种灰度结构；
3. 选择 Art Direction；
4. Variables 与 Components；
5. 补全状态；
6. 响应式；
7. 生成代码；
8. 设计—实现差异审计。

## 最终交付

`.pen` 文件、代码、运行截图、P0–P3 差异表和 100 分自评。
