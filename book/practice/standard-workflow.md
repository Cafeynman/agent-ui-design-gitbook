# 标准工作流

{% stepper %}
{% step %}
### 1. 一页 Product & Page Brief
定义产品、用户、使用场景、页面任务、成功指标和禁止项。
{% endstep %}
{% step %}
### 2. 内容骨架
只确认内容与 Section 顺序，不加视觉风格。
{% endstep %}
{% step %}
### 3. 三种灰度结构
比较产品优先、证据优先和叙事优先等真实结构差异。
{% endstep %}
{% step %}
### 4. 三种 Art Direction
为颜色、字体、布局、图形语言和 Signature Element 提供依据。
{% endstep %}
{% step %}
### 5. 最小 Tokens 与 Components
只建立当前产品真实复用的部分。
{% endstep %}
{% step %}
### 6. State Inventory
补齐 Loading、Empty、Error、Success、Validation 和恢复。
{% endstep %}
{% step %}
### 7. Desktop / Mobile
明确重排规则和内容优先级。
{% endstep %}
{% step %}
### 8. Agent 实现
使用现有技术栈与组件，不擅自改变设计决策。
{% endstep %}
{% step %}
### 9. 截图差异审计
按 P0–P3 记录差异，先修任务阻断和无障碍问题。
{% endstep %}
{% step %}
### 10. 同步提交
将 `.pen`、代码、截图与 Review 记录一起版本管理。
{% endstep %}
{% endstepper %}
