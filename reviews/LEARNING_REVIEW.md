# 短课体验复查

本轮是同一助手的内容复核、代码审查与自动浏览器测试，不是独立子 Agent 审查。

## 复现并修复

| 问题 | 处理 | 验收 |
| --- | --- | --- |
| 手机点下一课后，标题在屏幕上方，焦点仍在下一课按钮 | 导航后焦点与滚动回到新课标题 | 标题进入视口；键盘焦点在标题 |
| 手机宽度示例实际超出容器，却被 overflow:hidden 隐藏，原测试只检查页面总宽 | 限制内部网格轨道，滑块上限取真实可用宽度，移除宽度过渡 | 320/390/768/1440px、最大与最小宽度均不被裁切；数字匹配实际宽度 |
| 手机无法展示宽屏布局，容易只看到一列却不懂为什么 | 加入可展开的宽窄排法示意 | 实际演示仍按真实宽度排版；对照明确标为示意 |
| 选择含糊标题后，提示却赞扬具体标题 | 各种选择和滑块数值对应自己的说明 | 反例不再收到正例反馈 |
| 状态示例重试成功后，选中项仍是失败 | 高亮跟随实际状态 | 结果与选中项一致 |
| 第一课题目突然引入“首屏范围”，增加新词负担 | 改为判断哪句话更能说明用途；概念区别保留在展开说明 | 默认一课只学一个判断 |
| 再访已完成课程，说明却要求重新完成 | 完成提示读取已保存记录 | 重访课程仍显示已完成 |
| 跳到当前课程链接触发路由，重置回第一课 | 独立处理跳转，不更改课程 | 在任意课程点击都保留当前课 |
| 快速更换导入文件时，较慢的旧读取可能覆盖新选择 | 给读取编号，关闭对话框也使待处理读取失效 | 迟到结果不恢复旧确认按钮 |

## 可复验

```sh
python scripts/build.py
python scripts/check.py
python scripts/browser_check.py
python scripts/review_check.py
```

原有 97 项检查保留，新增 44 项针对性检查。CI 会用真实 HTTP 环境执行两套脚本并上传报告；运行结果以对应提交的 Actions 为准。

本地沙箱 HTTP 被策略禁止时，可用 `CHROMIUM_PATH=/usr/bin/chromium python scripts/review_check.py --fixture`。该模式使用内存 HTML 和模拟存储，只证明交互与布局，不代替真实存储验证。

## 边界与后续

未做独立模型复审、Safari/Firefox、屏幕阅读器实测、真实初学者试用。下一步优先观察初学者能否把一条指令用于自己的页面，不继续堆术语。

GitHub Pages 的账户设置与源码修改分开。本轮不修改其他仓库，不强推重写历史，不创建新的发布分支，不把测试通过说成公网已发布。
