# 本轮审查记录

## 审查性质

独立子 Agent：未运行。当前连接没有可调用的独立 Agent 执行器。以下是内容复核、静态检查及浏览器自动化，不冒称多人独立审查。

## 发现并处理

| 问题 | 处理 |
| --- | --- |
| 远程 main 只有占位内容，之前发布说法不可靠 | 从可验证 Git 对象恢复书稿；新发布必须校验实际提交号 |
| 新手先看到大量术语，入口过重 | 默认展示一节可操作的短课；查词、长文作为次级入口 |
| Hero 与首屏范围容易混淆 | 第 1 课解释区域和可见范围的区别 |
| Modal 和 Drawer 被错误当作互斥分类 | 区分阻止背景操作的行为与侧边出现的位置 |
| 光勾“学会”不能证明做过练习 | 操作示例且答对才记为完成；明确完成不等于掌握 |
| 错误反馈只有术语，没有修复路径 | 可实际提交错误邮箱、修改、重新提交 |
| 学习记录导入不应默默覆盖 | 大小限制、ID 校验、预览确认、合并而非覆盖 |
| 不能把 HTTP 200 当作上线成功 | version.json 记录真实源码 SHA；部署后读取并匹配 |
| 不能把自查当独立 Agent 结果 | 报告明确标记检查方式与未执行项 |

## 检查范围

静态脚本检查内部文件链接、HTML ID、label 关联、JavaScript 语法、词条数。浏览器脚本检查 12 课、答案反馈、错误恢复、焦点、搜索、记录导入、存储降级，以及 320/390/768/1440 像素布局。

本地环境禁止浏览器访问 HTTP，本地视觉复核使用内存 HTML，60 项 DOM/布局检查通过；本地持久化在该模式下为模拟，不能当作真实存储验证。GitHub Actions 会另跑真实 HTTP 环境的完整脚本，是否通过以实际运行报告为准。
